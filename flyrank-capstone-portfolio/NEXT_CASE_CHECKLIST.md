# Next Case Checklist

Quick reference for adding a new case study to README.md.

## Before you start
- [ ] The project is shipped or at a stable stopping point
- [ ] You have rough notes on what the problem was and what you built

## Writing the case (three beats)
- [ ] Problem — one or two sentences on what was broken or unknown
- [ ] What I did — concrete actions, tools, decisions (not just "I built a thing")
- [ ] What came of it — what you can now do or see that you couldn't before

## Adding it to the portfolio
- [ ] Copy an existing `###` block in README.md
- [ ] Fill in all three beats
- [ ] Update the **Up Next** section to the following planned case
- [ ] Update the reminder date if needed
- [ ] Commit: `git commit -m "portfolio: add [project name] case study"`

## Claude Project shortcut
Open the Claude Project → paste your rough notes → ask:
"Shape this into the three-beat case study format, matching my existing voice."
First draft done in one conversation.
